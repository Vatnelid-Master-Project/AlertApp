# APP Client

The app's main resposibility is to connect and recive notifications from the API.

The app is build using TypeScript and Expo for enabling React Native. 

Make sure to have set up the API correctly before starting on the app setup.
For development environment: create .env.development, and fill in the variables accordingly as in 
.env.example.

When everything is is set up, make sure to have node >= 20.19.6, npm and nvm installed and run ```npm install``. 

Start development server using ```npm start``` or ```npm start-local``` and follow the instrucitons.
